# comfyatmos: the new file names

## What changed

From v0.10.0-alpha the files are `comfyatmos.dll`, `comfyatmos.ini`, `comfyatmos.log` and the `comfyatmos-cache` folder.
They were `comfyfog.dll`, `comfyfog.ini`, `comfyfog.log` and `comfyfog-cache`, from the first version, which only did
fog.

## Old files

- **Both DLLs loaded:** `comfyatmos.dll` stays off while `comfyfog.dll` is loaded, and `comfyatmos.log` says so. Two
  copies would draw each effect twice.
- **Only the old ini:** without a `comfyatmos.ini`, the DLL reads `comfyfog.ini`, and the log says so.
- **The controls** keep their CVar names, so the values set on the Atmosphere page are kept.

## The other mods

comfytime, comfyaim and wow-test-tool's comfytest wait for comfyatmosphere to patch first, as they waited for
`comfyfog.dll`. They know both names. With both loaded they wait for the old one, the one that patches.
